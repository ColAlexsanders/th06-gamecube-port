# Touhou 6 EOSD Gamecube Port

Making this public because @niko1official got this ported out to the wii (https://github.com/niko1official/th06-wii)

I want to make this because 1. I want to play this game on the gamecube and 2. Just in case the remaster (or remake idek at this point) completely blows.

I am using the code from https://github.com/GensokyoClub/th06/tree/portable for the actual game, so most of the code in this is stolen from GensokyoClub and their contributors. What I need to do is to replace the SDL2 and OpenGL related logic with libogc2. 

I haven't got into actual testing yet. I still need to do some replacements
